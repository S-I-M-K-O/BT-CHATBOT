Voice & speech

On: Chrome sends what you say to Google to turn it into text. Off: speech is recognised on this device only (needs a recent Chrome; the language pack downloads once). If on-device recognition isn't available, voice input stays off and typing still works.

    Format

    One “key = value” per line, keys as in the export. # starts a comment, [sections] are only for order. true/false, numbers, text (in "quotes" only when needed). Tokens, passwords and the PIN do not belong here — they stay in .env or in this window.

    # HERMES
[general]
uiLang = de
speak = true

[voice]
piperVoice = JarvisDE
voiceSpeed = 1.1
